## How to use:
 First, ensure you have flask installed on your pip. The pip list command easily showcases your installed packages. (install via pip install Flask)
 After ensuring flask is installed, open this cloned repository's server/app.py file and open pipenv shell to start a virtual environment.
 Through this virtual environment, start the local host using the command python app.py or flask run.
 Then open postman (or a different API client) and begin to test the different methods - Get, Post, Patch and Delete, implemented into this project.
